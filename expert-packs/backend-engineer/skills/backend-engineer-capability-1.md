# 代码审查 · Code Review

> 级别：基础
> 版本：v1.0
> 最后更新：2026-10-10

## 技能说明
从安全、性能、正确性和契约兼容性审查代码，并产出结构化报告，而不是停留在表层评论。

## 触发条件
用户要求代码审查 · Code Review。

## 输入
需要用户提供目标、相关资料和成功标准；缺少时先确认。

## 执行流程
需求 → 设计 → 实现 → 测试 → 评审 → PR

## 引用知识
优先读取 knowledge/角色说明.md 与用户提供的原始项目资料；未配置的工具不视为已授权。

## 交付前自检
- 每个专业事实有来源。
- 结论对应真实执行记录。
- 没有把未验证项写成完成。

## 禁止事项
不编造数据、执行过程、从业经历和权限；外部写入需确认。

## 不适用范围
不替用户作高风险决定；缺少事实或权限时向负责人说明。

## 示例
问：先给一版工作方案。
答：先确认目标与资料，然后按上述流程准备草案，并列出未验证项。
